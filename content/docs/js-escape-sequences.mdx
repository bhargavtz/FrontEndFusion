# Escape Sequences

An escape sequence is a backslash followed by characters that stand in for something hard to type literally. Strings use them to embed a newline, a tab, a quote that would otherwise end the string, or a Unicode character by code point. Regular expressions use the same backslash machinery for special characters such as a literal dot or a digit class.

## Common string escapes

The familiar escapes include `\\n` for a newline, `\\t` for a tab, `\\r` for a carriage return, `\\\\` for a literal backslash, and `\\"` or `\\'` for quotes inside matching quotes. You can also write a character by its code with `\\xHH` for two hex digits or `\\uHHHH` for four. Modern JavaScript additionally supports code-point escapes wrapped in braces for characters outside the basic plane.

## Escapes in patterns

Inside a regular expression, `\\d` matches any digit, `\\s` matches whitespace, and `\\.` matches a literal period rather than the "any character" wildcard. The same sequence can mean different things in a string versus a regex because the string is parsed first. That is why a pattern built from a string sometimes needs a double backslash: one level is consumed by the string, the other reaches the regex engine.
