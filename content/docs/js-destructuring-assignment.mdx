# Destructuring assignment

Destructuring is a shorthand for extracting several values from an array or object and assigning them to variables in one statement. It cuts down on repetitive property access and makes function signatures self-documenting.

## Object destructuring

Put a pattern of property names on the left of an assignment to pull matching values out of an object on the right:

```js
const user = { name: 'Ada', age: 36 };
const { name, age } = user;
```

Only the properties you list are extracted, and the variable names match the keys by default. The same syntax works in a `const`, `let`, or `var` declaration, or on its own inside parentheses when reassigning existing variables.

## Defaults, renaming, and nesting

If a property is missing, a default value keeps the variable defined: place an equals sign after the name. To use a different local name, write the source key followed by a colon and the new name, and a default can follow that. Patterns can be nested to dig into structured data, such as pulling a city from an address object inside a user.

```js
const { name: fullName, role = 'Guest', address: { city } } = user;
```

## Array destructuring and function arguments

Array patterns use square brackets and follow position rather than names. You can skip slots with a gap, and a rest pattern gathers the remaining items into a new array. Destructuring is especially common in function parameters: an options object becomes a clean list of named arguments with defaults, which removes the need for a block of `if` statements filling in missing settings.
