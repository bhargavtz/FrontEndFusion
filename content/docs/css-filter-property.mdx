# Filter Property

`filter` applies graphic effects to an element's rendered pixels, including its children, borders, and backgrounds. One declaration can desaturate a thumbnail, blur a backdrop, or push a whole panel into a duotone.

## The common functions

`blur(radius)` softens edges. It takes a length; `0` is a no-op. Blur spreads beyond the element's border box in some browsers, so a container with `overflow: hidden` prevents bleed.

`drop-shadow(x y blur color)` follows the alpha shape of the element rather than its rectangular box, which is what makes it ideal for PNG cutouts, icons, and CSS-drawn blobs. It differs from `box-shadow` in exactly that way.

`hue-rotate(angle)` rotates colors around the hue wheel. It is a cheap way to produce a second colorway from one asset, though it shifts every color in the element.

`grayscale(amount)` goes from `0` to `1`, or a percentage. `sepia()` warms an image into a vintage tone. `brightness()`, `contrast()`, and `saturate()` take a factor where `1` is unchanged. `invert()` flips colors and is frequently used for dark-mode image treatments — `invert(1)` on a black icon yields white.

## Combining filters

Multiple functions are space-separated in one declaration and apply in order, left to right:

```css
.hero {
  filter: grayscale(0.7) contrast(1.1) brightness(1.05);
}
```

Order changes the result. Filters are also computationally heavier than a transform, so animate `opacity` or `transform` when you can, and avoid filtering large areas during scrolling. A filter on an element creates a containing block for fixed descendants, like `transform` does.

CSS also offers `backdrop-filter`, which filters whatever sits behind the element — the basis of frosted glass panels.
