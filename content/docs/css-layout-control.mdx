# Layout Control

`display` decides two things at once: whether an element generates a box at all, and how that box behaves toward its siblings and children. Most layout bugs come down to picking the wrong value here.

## The core values

`block` boxes take the full available width, start on a new line, and accept width, height, and vertical margins. Headings, paragraphs, and `div` elements default to this.

`inline` boxes flow with text, ignore width and height, and only accept horizontal margins and padding. Vertical padding paints but does not push lines apart, which is why inline links with padding can overlap the line above.

`inline-block` sits in the text flow but accepts full box dimensions. It was the standard way to build card grids and navigation bars before Flexbox, and it still fits small chips or icon buttons. Watch out for the whitespace gap between inline elements — it comes from real spaces in your HTML.

`flex` turns the element into a one-dimensional layout container. Children line up along a main axis, distribute free space, and align on the cross axis. It is the right tool for navbars, toolbars, and card rows.

`grid` is two-dimensional: columns and rows are defined together, and children can be placed into cells. Use it for page shells, dashboards, and galleries.

`none` removes the element and its subtree from rendering. The space collapses and the content is hidden from assistive technology. To hide visually while keeping it accessible, use a clipping pattern instead.

## Old table-like layouts

Before Flexbox, developers faked columns with `display: table`, `table-row`, and `table-cell`. Equal-height columns and vertical centering came free, which was hard to achieve otherwise. The pattern still appears in older codebases and in email templates, so it is worth recognising. Prefer Flexbox or Grid for new work; keep the table display only when you genuinely need its sizing behavior.

`float` was the other workhorse. It remains useful for wrapping text around a figure, but float-based page layouts need clearfix hacks and break easily.

## Demo: the same card row, three ways

```html
<div class="board">
  <section>
    <h2>inline-block</h2>
    <div class="row row--inline">
      <div class="card">Starter</div>
      <div class="card">Studio</div>
      <div class="card">Scale</div>
    </div>
  </section>

  <section>
    <h2>flex</h2>
    <div class="row row--flex">
      <div class="card">Starter</div>
      <div class="card">Studio</div>
      <div class="card">Scale</div>
    </div>
  </section>

  <section>
    <h2>table-cell centering</h2>
    <div class="row row--table">
      <div class="card card--center">Legacy, still centered</div>
    </div>
  </section>
</div>
```
