# Async functions (async/await)

An `async` function is one declared with the `async` keyword. It always returns a promise, and inside it you can pause with `await`, which waits for a promise to settle and then resumes the function with the resolved value. The result is asynchronous code that reads top to bottom, without the nested callbacks that promises alone can encourage.

## Await and operator precedence

The `await` operator unwraps a promise, so `await somePromise` produces the value rather than the promise itself. It only has meaning inside an `async` function or at the top level of a module. If you await a non-promise, the value is passed through unchanged. Errors thrown while awaiting are caught with a normal `try` and `catch` block, which is one of the biggest readability wins over chained `catch` handlers.

## Sequential versus parallel work

Awaiting inside a loop runs each operation one after another, which is correct when steps depend on each other. When tasks are independent, start them all and then await the combined promise with `Promise.all` so they overlap. The demo uses a small local delay helper to compare both approaches: sequential awaits add their wait times together, while the parallel version finishes in roughly the time of the slowest step.

      var out = document.getElementById("out");
      function step(n) {
        return new Promise(function (resolve) {
          window.setTimeout(function () { resolve("task " + n + " done"); }, 500);
        });
      }
      async function sequential() {
        var lines = ["Sequential run:"];
        var start = Date.now();
        for (var i = 1; i <= 3; i++) {
          lines.push("await -> " + await step(i));
          out.textContent = lines.join("\n");
        }
        lines.push("total -> " + (Date.now() - start) + " ms");
        out.textContent = lines.join("\n");
      }
      async function parallel() {
        var start = Date.now();
        var results = await Promise.all([step(1), step(2), step(3)]);
        out.textContent = "Parallel run:\n" + results.map(function (r) { return "await all -> " + r; }).join("\n") +
          "\ntotal -> " + (Date.now() - start) + " ms";
      }
      document.getElementById("seq").addEventListener("click", sequential);
      document.getElementById("par").addEventListener("click", parallel);
    </script>
  </body>
