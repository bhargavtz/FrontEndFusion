# Character Entities

Some characters have special meaning in HTML. Others are hard to type. Character references let you write them safely.

## Character entities in HTML

```html
<p>Use &lt; and &gt; to show angle brackets in text.</p>
<p>The ampersand is written as &amp;.</p>
<p>Quotes: &quot;double&quot; and &apos;single&apos;.</p>
```

Without escaping, `<button>` inside a paragraph would be parsed as an actual element.

## Common special characters

| Character | Named reference | Numeric reference |
| --- | --- | --- |
| `&` | `&amp;` | `&#38;` |
| `<` | `&lt;` | `&#60;` |
| `>` | `&gt;` | `&#62;` |
| `"` | `&quot;` | `&#34;` |
| `'` | `&apos;` | `&#39;` |
| non-breaking space | `&nbsp;` | `&#160;` |
| `©` | `&copy;` | `&#169;` |
| `®` | `&reg;` | `&#174;` |
| `™` | `&trade;` | `&#8482;` |
| `€` | `&euro;` | `&#8364;` |
| `£` | `&pound;` | `&#163;` |
| `—` | `&mdash;` | `&#8212;` |
| `–` | `&ndash;` | `&#8211;` |
| `…` | `&hellip;` | `&#8230;` |
| `←` | `&larr;` | `&#8592;` |
| `→` | `&rarr;` | `&#8594;` |
| `✓` | `&check;` | `&#10003;` |

## Numeric references

Numeric references work even when a named entity is not supported:

```html
<p>Copyright &#169; 2026</p>
<p>Euro price: &#8364;49</p>
<p>Arrow: &#8594;</p>
```

Hexadecimal references are also valid:

```html
<p>Heart: &#x2764;</p>
```

## When to use entities

- Escape `&`, `<`, and `>` when they are text.
- Escape quotes inside attribute values when the same quote character would end the value.
- Use `&nbsp;` sparingly; it prevents wrapping and can hurt responsive layouts.
- Use the actual Unicode character when the document is UTF-8 and the character is easy to type.

## Common mistake

```html
<!-- Wrong: the browser sees a tag, not text -->
<p>Use <div> for a block container.</p>

<!-- Right -->
<p>Use &lt;div&gt; for a block container.</p>
```

Set `<meta charset="utf-8">` and save files as UTF-8 so that characters such as `é`, `→`, and `✓` display correctly without extra entities.
