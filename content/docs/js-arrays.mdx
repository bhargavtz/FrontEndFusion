# Arrays

An array is an ordered list of values held under numeric indexes starting at zero. It is the workhorse of JavaScript data handling, and modern array methods let you describe transformations without writing manual loops.

## Creating and reading arrays

Create an array with square brackets, such as `var items = ["tea", "coffee"]`. Read an element by index with `items[0]`, and find how many elements it holds with `items.length`. The `push` and `pop` methods add or remove from the end, while `unshift` and `shift` work at the front. Indexes that do not exist return `undefined`, so guard your access when reading user-provided positions.

## Transforming with map, filter, and reduce

These three methods form the core of array processing, and each returns a new result rather than changing the original. `map` applies a function to every element and builds an equally long array of results. `filter` keeps only the elements whose callback returns a truthy value. `reduce` walks the list while carrying an accumulator, collapsing it to a single value such as a total or an object. Their callbacks receive the current element, its index, and the whole array, which is handy when position matters.

## Other handy moves

`sort` orders elements in place; pass a comparison function for numbers, since the default sorts by string value. `find` returns the first matching element and `includes` tests membership. The spread syntax `...` copies an array or concatenates several, and destructuring unpacks positions into named variables, such as `var [first, second] = items`. To remove duplicates, pass the array to a `Set` and spread it back. `slice` gives a shallow copy of part of an array, while `splice` changes the original by inserting or deleting.

## Demo: expense tracker

The demo filters a small expense list by category. `filter` selects the visible rows, `map` rounds the amounts, and `reduce` computes the total.

```html
<div class="wrap">
  <div class="card">
    <h2>Expense tracker</h2>
    <p class="hint">Pick a category to see filter, map, and reduce at work.</p>
    <div class="filters">
      <button data-cat="all" class="active">All</button>
      <button data-cat="food">Food</button>
      <button data-cat="travel">Travel</button>
      <button data-cat="tools">Tools</button>
    </div>
    <ul id="list"></ul>
    <div class="summary" id="summary"></div>
  </div>
</div>

<script>
  var expenses = [
    { name: "Lunch", cat: "food", amount: 12.5 },
    { name: "Train ticket", cat: "travel", amount: 24 },
    { name: "Notebook", cat: "tools", amount: 8.75 },
    { name: "Coffee", cat: "food", amount: 4.25 },
    { name: "USB cable", cat: "tools", amount: 11 }
  ];
  var current = "all";

  function render() {
    var shown = expenses.filter(function (e) {
      return current === "all" || e.cat === current;
    });
    var list = document.getElementById("list");
    list.innerHTML = "";
    shown.forEach(function (e) {
      var li = document.createElement("li");
      var label = document.createElement("span");
      var amount = document.createElement("span");
      label.textContent = e.name;
      amount.textContent = "$" + e.amount.toFixed(2);
      li.appendChild(label);
      li.appendChild(amount);
      list.appendChild(li);
    });
    var total = shown.reduce(function (sum, e) { return sum + e.amount; }, 0);
    var rounded = shown.map(function (e) { return Math.round(e.amount); });
    var roundedSum = rounded.reduce(function (a, b) { return a + b; }, 0);
    document.getElementById("summary").textContent =
      shown.length + " items · total $" + total.toFixed(2) +
      " · rounded sum $" + roundedSum;
  }

  Array.prototype.forEach.call(document.querySelectorAll(".filters button"), function (btn) {
    btn.addEventListener("click", function () {
      current = btn.dataset.cat;
      Array.prototype.forEach.call(document.querySelectorAll(".filters button"), function (b) {
        b.classList.remove("active");
      });
      btn.classList.add("active");
      render();
    });
  });
  render();
</script>
```
