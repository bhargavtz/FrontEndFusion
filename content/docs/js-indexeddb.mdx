# IndexedDB

IndexedDB is a browser database for storing substantial amounts of structured data, including files and blobs. It is asynchronous, transactional, and organised into databases, object stores, and indexes. Unlike `localStorage`, it handles large datasets without blocking the main thread.

## Opening a database

You start with `indexedDB.open(name, version)`. The request exposes `onsuccess`, `onerror`, and `onupgradeneeded` events. The upgrade event fires when the database is new or its version increases; that is where you create object stores with `createObjectStore` and define indexes. Everything else happens after the open request succeeds.

## Adding and retrieving objects

Writes and reads take place inside transactions. You obtain a transaction for one or more stores, get the store object, and call `add` or `put` to insert data. `add` fails if the key already exists, while `put` overwrites it.

To read, call `get(key)` for a single record, `getAll()` for every record, or use an index for a filtered lookup. Each call returns another request with its own success handler. Because operations are asynchronous, you chain work through callbacks, promises, or `async`/`await` wrappers rather than reading results synchronously.

## Testing for availability

Some environments block IndexedDB entirely, so check for `window.indexedDB` before using it and show a fallback. The demo keeps a tiny in-memory object store with the same conceptual steps, which lets you try adding and listing records even when the real API is unavailable. A message tells you whether live IndexedDB was detected.

      var out = document.getElementById("out");
      var list = document.getElementById("list");
      var hasIDB = "indexedDB" in window;
      var store = {};
      document.getElementById("note").textContent = hasIDB
        ? "Live IndexedDB is available. This sandbox demo uses an in-memory store to stay predictable. In a real app you would open a database inside onupgradeneeded and create an object store."

      function refresh() {
        list.innerHTML = "";
        Object.keys(store).forEach(function (k) {

          li.textContent = k + " -> " + store[k];

        });

        var k = document.getElementById("key").value.trim();

        store[k] = v;
        refresh();
        out.textContent = "put('" + k + "', '" + v + "') succeeded\ngetAll() now returns " + Object.keys(store).length + " record(s).";
      });
      document.getElementById("clear").addEventListener("click", function () {
        store = {};
        refresh();
        out.textContent = "Object store cleared.";
      });
      refresh();
      out.textContent = "Open database 'demo', version 1\nCreate object store 'notes' with keyPath 'id'\nReady for put() / get() / getAll()";
