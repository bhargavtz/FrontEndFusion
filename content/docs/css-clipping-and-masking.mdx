# Clipping and Masking

Clipping and masking both hide part of an element, but they hide it in different ways. A clip is a hard-edged path: everything outside the path disappears. A mask is a transparency map: each pixel of the mask decides how much of the element shows through, so you can fade, feather, or punch holes.

Both are paint-time operations. The element still occupies its original box in layout, so surrounding content does not reflow.

## Hard edges with clip-path

`clip-path` accepts basic shapes and arbitrary polygons:

- `circle(50% at 50% 40%)` — a circle centred slightly high, the standard avatar crop.
- `ellipse(60% 40% at 50% 50%)` — oval framing for portraits.
- `inset(12px 24px round 18px)` — a rounded rectangular crop, useful for photo cards.
- `polygon(50% 0, 100% 25%, 100% 75%, 50% 100%, 0 75%, 0 25%)` — a hexagon badge.
- `path("...")` — an SVG path for anything hand-drawn.

Shapes in the same functional family animate between each other, so a hover that grows a circle from `0%` to `50%` is smooth. Percentages resolve against the element's reference box, which makes shapes responsive without media queries.

## Soft edges with mask-image

`mask-image` takes an image, usually a gradient. Black is opaque, transparent is invisible, and grey is partial. That gives you effects a clip cannot produce:

- `linear-gradient(to bottom, #000 50%, transparent)` — text fading out at the bottom of a card.
- `radial-gradient(circle, #000 40%, transparent 70%)` — a spotlight vignette.
- `radial-gradient(circle 32px at 82% 20%, transparent 98%, #000 100%)` — a ticket with a punched hole, drawn as one gradient.

Add `mask-repeat: no-repeat` and `mask-size: 100% 100%` so the gradient covers the element exactly once. Safari still wants the `-webkit-mask-image` alias in production, and masking is more expensive to repaint than clipping, so avoid animating it on large surfaces.

Accessibility note: content hidden by a clip or mask is still in the accessibility tree and still focusable. If a control is visually cut away, hide it for real with `display: none` or `visibility: hidden` rather than relying on paint alone.
