# CSS Image Sprites

A sprite sheet is a single image that holds many small graphics arranged in a grid. Instead of requesting eight icons, you request one file and use `background-position` to crop the region you want. The classic use case is an icon set where the same element shows a muted icon at rest and a highlighted icon on hover.

The savings that made sprites famous — fewer HTTP requests — matter less over HTTP/2, but sprites still help when a set of states must paint instantly, and the technique is a good way to understand background geometry.

## How the crop works

The element is the window; the sprite is the film. Give the element the size of one cell, then shift the sheet by whole cells:

- `background-repeat: no-repeat` — otherwise the sheet tiles and you see neighbouring icons.
- `background-position: 0 0` — first cell, top-left.
- `background-position: -120px 0` — second column of a 120px grid.
- `background-position: -120px -120px` — second column, second row.

Negative offsets move the image up and left, so the cell you want slides into view. Keep the arithmetic aligned with `background-size`: if you scale the sheet down to 50%, every offset halves too. Percentage positions are the other option, but they are relative to the difference between element and image size, so a three-column sheet steps by `50%` and `100%`, not by a third.

## Hover states and a CSS-only sheet

The demo uses an inline SVG data URI as the sprite: three icons across, two rows deep. The top row is the resting style, the bottom row is the active style on a navy tile. Hovering a card moves `background-position` down by one row and the transition makes the swap feel intentional.

Sprites are pure presentation, so keep the artwork out of the accessibility tree with `aria-hidden` or `role="presentation"` and put the meaning in real text beside it. For an animated sprite, step the offset on a timer instead of relying on hover — the geometry is exactly the same.
