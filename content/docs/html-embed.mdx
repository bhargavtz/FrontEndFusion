# Embed

The `embed` element embeds external content that the browser can render with a plugin or a built-in viewer.

## Basic usage

```html
<embed
  src="https://picsum.photos/seed/embedded/480/260"
  type="image/jpeg"
  width="480"
  height="260"
  title="Embedded landscape photo"
/>
```

`embed` is a void element. It has no fallback content of its own, so provide a link nearby if the content is important.

## Defining the MIME type

The `type` attribute tells the browser what kind of content to expect:

```html
<embed src="/media/report.pdf" type="application/pdf" width="100%" height="420" />
<embed src="/media/diagram.svg" type="image/svg+xml" width="320" height="200" />
<embed src="/media/loop.webm" type="video/webm" width="320" height="180" />
```

If the browser cannot render the type, it may show nothing. Always provide an alternative:

```html
<p>
  <a href="/media/report.pdf">Download the report (PDF)</a>
</p>
```

## When to use embed

- For a quick, plugin-style embed of a single resource.
- For legacy content that expects a plugin.
- For a simple PDF or SVG viewer.

For modern layouts, prefer:

- `img` for images.
- `video` and `audio` for media.
- `iframe` for other HTML pages.
- `object` when you need fallback content.

## Accessibility

- Add a `title` attribute to describe the embedded content.
- Provide a text alternative or download link.
- Do not embed essential information only inside a plugin.
- Check keyboard access to the embedded content.
