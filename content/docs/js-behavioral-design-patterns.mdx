# Behavioral Design Patterns

Behavioral patterns describe how objects interact and share responsibility. They are less about creating objects and more about keeping the flow of control clean as a system grows. Four useful ones are the observer, mediator, command, and iterator patterns, each solving a different kind of coupling problem.

## Observer and mediator

The observer pattern defines a subject that maintains a list of dependents and notifies them automatically when its state changes. Subscribers register a callback, and the subject broadcasts an update to all of them. This keeps the subject from knowing anything specific about its observers. The mediator pattern goes a step further: instead of many objects referring to each other directly, they communicate through a central mediator, which reduces a web of connections to a hub-and-spoke arrangement.

## Command and iterator

A command turns a request into an object, bundling the action with its arguments so it can be passed around, queued, or undone later. A button and a menu item can share the same command object without either knowing how it is carried out. The iterator pattern provides a uniform way to walk through a collection without exposing how that collection stores its elements, which is why methods like `values` and generators are so common in modern JavaScript.

## A live observer feed

The demo implements a small news subject with three subscribers. Toggle a subscriber on or off, publish a headline, and watch only the active observers receive it. The publish action is itself a command object, showing how a request can be represented as data.

    <script>
      var out = document.getElementById("out");
      var lines = [];
      function log(text) {
        lines.push(text);
        if (lines.length > 8) lines.shift();
        out.textContent = lines.join("\n");
      }
      function Subject() { this.observers = []; }
      Subject.prototype.subscribe = function (name, fn) { this.observers.push({ name: name, fn: fn, active: true }); };
      Subject.prototype.publish = function (value) {
        this.observers.forEach(function (o) { if (o.active) o.fn(value); });
      };
      var news = new Subject();
      document.querySelectorAll("[data-ch]").forEach(function (box) {
        var name = box.getAttribute("data-ch");
        var toggle = box;
        news.subscribe(name, function (value) {
          log(name + " observer -> " + value);
        });
        toggle.addEventListener("change", function () {
          news.observers.forEach(function (o) { if (o.name === name) o.active = toggle.checked; });
        });
      });
      var publishCommand = { execute: function (text) { news.publish(text); } };
      document.getElementById("publish").addEventListener("click", function () {
        var text = document.getElementById("headline").value.trim() || "(untitled)";
        log("command execute -> " + text);
        publishCommand.execute(text);
      });
    </script>
