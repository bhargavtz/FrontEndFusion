# Inheritance

Inheritance lets one object reuse another object's behavior without duplicating code. JavaScript implements this with the prototype chain: a lookup that fails on the current object continues up through its ancestors until it finds a match or reaches the end.

## The chain behind every object

Setting up inheritance manually is straightforward with `Object.create(parent)`. The new object's internal link points at `parent`, so any property missing locally is looked up there. You can add your own fields to shadow inherited ones while still reaching the shared methods.

In the older constructor pattern, you assign a prototype object to the child constructor's `prototype` and then repair its `constructor` property. One subtlety is worth remembering: a method on the prototype is shared, but a field written on an instance belongs only to that instance. Also, a property found directly on an object takes precedence over the identical name further up the chain.

## Extending with classes

Class syntax expresses the same idea more plainly. `extends` establishes the link, `super()` in the constructor runs the parent setup, and `super.method()` calls a parent implementation from an override. Subclasses can add fields, replace methods, and still inherit everything they did not touch.

Both styles produce the same chain. Classes are not a separate inheritance model, just a friendlier notation over the prototype machinery.

One limitation is worth flagging. Inheritance creates tight coupling: a child depends on the parent's field names and method behavior. If the parent changes, every descendant may need attention. Composition, where an object holds another object and delegates to it explicitly, is often the calmer long-term choice.

<script>
  class Vehicle {
    constructor(name, wheels) {
      this.name = name;
      this.wheels = wheels;
      this.running = false;
    }
    start() {
      this.running = true;
      return this.name + " starts";
    }
    describe() {
      return this.name + " rolls on " + this.wheels + " wheels";
    }
  }

  class Car extends Vehicle {
    constructor(name) { super(name, 4); }
    describe() { return super.describe() + " inside a sealed cabin"; }
  }

  class Bicycle extends Vehicle {
    constructor(name) { super(name, 2); }
    start() { return super.start() + " after a good push"; }
  }

  var fleet = [];
  var list = document.getElementById("list");
  var out = document.getElementById("out");

  function render() {
    list.innerHTML = "";
    fleet.forEach(function (v) {
      var row = document.createElement("div");
      row.className = "vehicle";
      row.textContent = v.describe() + (v.running ? " - running" : " - parked");
      list.appendChild(row);
    });
    out.textContent = fleet.length ? "Fleet has " + fleet.length + " vehicle(s)." : "Fleet is empty.";
  }

  document.getElementById("addCar").addEventListener("click", function () {
    fleet.push(new Car("Sedan"));
    out.textContent = "Car inherits describe from Vehicle and adds its own detail.";
    render();
  });
  document.getElementById("addBike").addEventListener("click", function () {
    fleet.push(new Bicycle("Racer"));
    out.textContent = "Bicycle overrides start but still calls the parent version first.";
    render();
  });
  document.getElementById("addScooter").addEventListener("click", function () {
    var scooter = Object.create(Vehicle.prototype);
    scooter.name = "Scooter";
    scooter.wheels = 2;
    scooter.running = false;
    fleet.push(scooter);
    out.textContent = "Scooter was built with Object.create, with no constructor at all.";
    render();
  });
  document.getElementById("startAll").addEventListener("click", function () {
    out.textContent = fleet.length
      ? fleet.map(function (v) { return v.start(); }).join(" | ")
      : "Nothing to start yet.";
    render();
  });

  render();
</script>
