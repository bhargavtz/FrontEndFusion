# Strings

Strings hold text. Whether you are showing a user's name, parsing a sentence, or building markup, you will constantly create and reshape strings. JavaScript gives them a length, numeric indexes, and a large set of helpful methods.

## Creating and combining strings

A string can be written with single quotes, double quotes, or backticks. Backticks create template literals, which allow line breaks and interpolation with placeholders. The plus sign joins strings together, and `+=` appends to an existing one. To place a quote inside a string, either use the other kind of quote around it or escape it with a backslash.

Strings are sequences of Unicode characters, so many symbols and emoji work as expected. Keep in mind that indexing counts code units, which can split certain characters; iterating with a `for...of` loop handles full characters more safely.

## Searching, slicing and replacing

You can read a character at a position with `charAt()` or bracket indexing. `indexOf()` returns the first position of a substring, or minus one when it is absent, and `includes()` gives a simple boolean. `slice(start, end)` extracts a portion without changing the original, and `split(separator)` breaks a string into an array of pieces.

For replacements, `replace(oldText, newText)` swaps the first match; a regular expression with a global flag replaces all of them. These methods never modify the source string — they return a new one, because strings are immutable.

## Case, repetition and counting words

`toUpperCase()` and `toLowerCase()` change case, `repeat(n)` concatenates a string with itself a given number of times, and `trim()` removes surrounding whitespace. A common exercise is counting words: trim the input, split on runs of whitespace, and count the resulting items. Checking whether a value is a string is simply `typeof value === "string"`.
