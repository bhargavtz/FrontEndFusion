# Tilde ~

The tilde `~` is the bitwise NOT operator. It converts its operand to a signed 32-bit integer, flips every bit, and returns the result as a number. For whole numbers the effect is compact and predictable: `~5` is `-6`, `~0` is `-1`, and `~-2` is `1`. The general rule is `~x === -(x + 1)` for values that fit in 32 bits.

## The double tilde

Applying the operator twice cancels the flip: `~~x === x` for integers in range. Because the first conversion throws away any fractional part, `~~` is a quick way to truncate a number toward zero. It behaves like `Math.trunc()` for values inside the 32-bit range, and unlike `parseInt()` it does not try to read a number from the start of a string — it coerces the whole value first. Values outside that range wrap around, so very large numbers give surprising answers.

## Coercion, decimals and shorthands

Operands are converted with the same rules as other bitwise operators: strings become numbers, `null` becomes `0`, booleans become `0` or `1`, and anything that cannot be converted becomes `0`. That is why `~~"42"` is `42`, `~~true` is `1`, and `~~"abc"` is `0`. A classic shorthand test is `~text.indexOf(needle)`, which is `0` (falsy) when the item is found and nonzero when it is missing — though `includes()` is clearer in modern code. For decimals, `~~3.9` is `3` and `~~-3.9` is `-3`, truncating toward zero rather than rounding.
