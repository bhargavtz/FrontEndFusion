# Comments

A comment is a note for people that the JavaScript engine ignores completely. Comments explain *why* a piece of code exists, record a workaround, or temporarily disable a line while you experiment. They never affect the result of a program.

## Line and block comments

JavaScript has two comment forms. A double slash starts a single-line comment that runs to the end of the line. A slash and an asterisk start a block comment that continues until a matching asterisk and slash. Block comments can span several lines, but they cannot be nested.

```js
// A single line comment explains the next statement.
let total = 0;

/*
  This block comment can stretch over
  as many lines as you need.
*/
total = total + 1;
```

Comments inside strings are not comments at all — the text stays part of the string. The same applies to the two characters when they appear inside a regular expression literal. Keep comments short and current; an outdated note is worse than none.

## Why HTML comments are a poor choice in scripts

Very old JavaScript authors sometimes wrapped scripts in HTML comment markers so ancient browsers would not display the code as text. That trick is obsolete. Inside a script, a line beginning with the HTML open-comment marker is treated as a single-line JavaScript comment, but the closing marker on its own line is a syntax error in modern JavaScript. It also breaks under module scripts and strict mode. Use proper JavaScript comments instead.

The demo below shows a short commented program. Press the button to run it with and without the notes; the output stays the same because comments carry no instructions.

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Comments</title>
    <style>
      body {
        margin: 0;
        padding: 26px 18px;
        font-family: system-ui, sans-serif;
        color: #25303a;
        background: linear-gradient(140deg, #eef5ff, #faf7f0 70%);
      }
      .card {
        max-width: 560px;
        margin: 0 auto;
        padding: 22px;
        background: #ffffff;
        border-radius: 20px;
        box-shadow: 0 20px 42px -30px rgba(30, 50, 80, 0.5);
      }
      h1 { margin: 0 0 14px; font-size: 1.15rem; }
      pre {
        margin: 0;
        padding: 14px;
        border-radius: 12px;
        background: #1c2530;
        color: #d7e6f5;
        font-size: 0.78rem;
        line-height: 1.6;
        white-space: pre-wrap;
      }
      .note { color: #8fa3b8; }
      button {
        margin-top: 14px;
        padding: 10px 14px;
        border: 0;
        border-radius: 10px;
        background: #2d5fa8;
        color: #ffffff;
        font: inherit;
        font-size: 0.85rem;
        font-weight: 600;
        cursor: pointer;
      }
      .out {
        margin: 14px 0 0;
        padding: 12px;
        border-radius: 10px;
        background: #eef3fa;
        font-size: 0.85rem;
      }
    </style>
  </head>
  <body>
    <div class="card">
      <h1>Comments are invisible to the engine</h1>
      <pre><span class="note">// double the price during a sale</span>
let price = 40;
<span class="note">/* the multiplier is kept in one place
   so it is easy to change later */</span>
const sale = 2;
price = price * sale;</pre>
      <button id="run">Run the code</button>
      <pre id="out" class="out">Press the button to see the computed price.</pre>
    </div>
    <script>
      let runs = 0;
      document.getElementById("run").addEventListener("click", function () {
        runs += 1;
        // This line is a comment; it does not run.
        let price = 40;
        /* Neither does this block, no matter
           how many lines it spans. */
        const multiplier = 2;
        price = price * multiplier;
        document.getElementById("out").textContent =
          "Run " + runs + ": price = " + price +
          "\nThe comments changed nothing about the result.";
      });
    </script>
  </body>
</html>
```
