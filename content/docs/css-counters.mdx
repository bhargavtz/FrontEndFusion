# Counters

Counters are CSS variables with a numeric memory, incremented by the browser as it walks the tree. They exist because HTML's own numbering is rigid: an `ol` counts its direct items and nothing else. A counter can count across sections, restart inside a container, and be printed into `content` anywhere you like.

## The three-part contract

Every counter needs three declarations:

1. `counter-reset` creates the counter and sets its starting value. The default is `0`, and the property must be on an ancestor of the things being counted.
2. `counter-increment` adds to it. Put this on the element being numbered.
3. `content: counter(name)` displays it. This only works inside a pseudo-element.

```css
.steps { counter-reset: step; }
.steps li { counter-increment: step; }
.steps li::before {
  content: counter(step);
}
```

Nothing renders without the `::before` (or `::after`). The counter itself is invisible state; only `content` turns it into pixels.

The display side has its own formatting options: `counter()` takes an optional second argument naming a `list-style-type`. `decimal` is the default, but `upper-roman`, `lower-alpha`, `decimal-leading-zero`, and even `cjk-decimal` all work.

```css
content: counter(step, upper-roman) ".";
```

String fragments can be concatenated inside `content`, so adding a period, a dash, or the word "Step" is a matter of listing the pieces in order. Keep the punctuation in the CSS rather than in the markup — the number is generated, so its decoration should be too.

## Nesting with counters()

`counters()` is the plural form and it prints the whole ancestor chain, joined by a separator you supply. This is what produces numbering like `2.3.1`. Each level gets its own `counter-reset`, and the nested reset is what makes the inner counter start again for every parent.

```css
.chapter { counter-reset: section; }
.section { counter-reset: clause; }
.clause { counter-increment: clause; }
.clause::before {
  content: counters(clause, ".", decimal) " ";
}
```

The magic is in the implicit scope: a `counter-reset` on a descendant shadows any counter of the same name above it. So the inner list inherits the parent's current value for display, yet counts from one on each restart.

## A complete example

A three-level document outline numbers its chapters, sections, and clauses, and adds a roman-numeral summary block at the end.

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Counter outline</title>
    <style>
      body {
        margin: 0;
        padding: 44px 20px;
        font-family: system-ui, sans-serif;
        background: #eef3f9;
        color: #16203a;
        line-height: 1.6;
      }

      .doc {
        max-width: 580px;
        margin: 0 auto;
        padding: 32px 34px 36px;
        background: #fff;
        border-radius: 20px;
        box-shadow: 0 30px 60px -42px rgba(22, 32, 58, 0.6);
        counter-reset: chapter;
      }

      h1 {
        margin: 0 0 22px;
        font-size: 1.1rem;
        letter-spacing: 0.14em;
        text-transform: uppercase;
        color: #7183a1;
      }

      .chapter {
        counter-reset: section;
        margin-bottom: 18px;
      }

      .chapter > h2 {
        margin: 0 0 8px;
        font-size: 1rem;
        counter-increment: chapter;
      }

      .chapter > h2::before {
        content: "Chapter " counter(chapter) " · ";
        color: #4b6cf5;
        font-weight: 700;
      }

      .section {
        counter-reset: clause;
        margin: 0 0 10px 8px;
      }

      .section > h3 {
        margin: 0 0 6px;
        font-size: 0.9rem;
        color: #2d3b58;
        counter-increment: section;
      }

      .section > h3::before {
        content: counter(chapter) "." counter(section) "  ";
        font-variant-numeric: tabular-nums;
        color: #9aa8c0;
        font-weight: 600;
      }

      .clauses {
        margin: 0;
        padding: 0;
        list-style: none;
      }

      .clauses li {
        counter-increment: clause;
        padding: 3px 0 3px 6px;
        font-size: 0.84rem;
        color: #4e5c75;
      }

      .clauses li::before {
        content: counters(clause, ".") "  ";
        color: #b7c2d6;
        font-variant-numeric: tabular-nums;
        font-size: 0.76rem;
      }

      .summary {
        counter-reset: point;
        margin: 26px 0 0;
        padding: 16px 20px 16px 18px;
        background: #f5f8fd;
        border-left: 3px solid #4b6cf5;
        border-radius: 0 12px 12px 0;
        list-style: none;
        font-size: 0.84rem;
      }

      .summary li {
        counter-increment: point;
        padding: 3px 0;
      }

      .summary li::before {
        content: counter(point, upper-roman) ". ";
        color: #4b6cf5;
        font-weight: 700;
        font-size: 0.76rem;
      }
    </style>
  </head>
  <body>
    <div class="doc">
      <h1>Design system rules</h1>

      <div class="chapter">
        <h2>Foundations</h2>
        <div class="section">
          <h3>Colour</h3>
          <ul class="clauses">
            <li>Never invent a hue outside the token file.</li>
            <li>Text must clear 4.5:1 against its own background.</li>
          </ul>
        </div>
        <div class="section">
          <h3>Spacing</h3>
          <ul class="clauses">
            <li>Use the four-pixel scale only.</li>
            <li>Vertical rhythm beats optical guesswork.</li>
          </ul>
        </div>
      </div>

      <div class="chapter">
        <h2>Components</h2>
        <div class="section">
          <h3>Buttons</h3>
          <ul class="clauses">
            <li>One primary action per view.</li>
            <li>Disabled states keep their label.</li>
          </ul>
        </div>
      </div>

      <ol class="summary">
        <li>Tokens before one-off values.</li>
        <li>Contrast before aesthetics.</li>
        <li>Semantics before styling.</li>
      </ol>
    </div>
  </body>
</html>
```

The clause numbers read `1.1.1`, `1.1.2`, and then restart at `1.2.1`, because each `.section` resets its own `clause` counter. The chapter and section pieces come along for the ride through the same `counters()` call.
