# Date Comparison

Dates often need to be ordered: is this deadline in the past, which of two events happens first, and how many days separate them? JavaScript makes this straightforward because each `Date` holds a numeric value underneath.

## Comparing dates directly

You can use the relational operators `<`, `<=`, `>`, and `>=` on two `Date` objects. JavaScript converts each object to its numeric timestamp before comparing, so an earlier date is simply "less than" a later one.

Equality is different. Two separate `Date` objects are never strictly equal, even when they describe the same moment, because `===` compares object identity rather than content. To test whether two dates represent the same instant, compare their timestamps with `getTime()` or use the `valueOf()` result. The `+` operator also forces a date to its numeric form.

```js
const a = new Date("2026-01-01");
const b = new Date("2026-06-01");
a < b;                       // true
a.getTime() === b.getTime(); // false
```

## Calculating the difference

Subtracting one date from another gives the difference in milliseconds. Divide by the number of milliseconds in a day, `1000 * 60 * 60 * 24`, to get a fractional number of days. Use `Math.round()` or `Math.floor()` depending on whether you want the nearest whole day or whole days elapsed.

Be careful with calendar arithmetic across daylight-saving changes: a "day" measured in milliseconds can be 23 or 25 hours. For pure calendar counting, compare year, month, and day parts instead.
