# Flexible Box Layout (Flexbox)

Flexbox distributes space along a single axis. You declare a flex container, and its direct children become flex items that can grow, shrink, and align relative to that axis. Most layout problems that used to need hacks are now one or two properties.

## Centring and distributing space

`display: flex` turns on the formatting context. `justify-content` positions items along the main axis; `align-items` positions them across it. To centre one child completely, set both to `center` — and give the container a height, otherwise there is no vertical space to centre within. `gap` replaces margin arithmetic for spacing between siblings.

The axis flips with `flex-direction: column`, and `justify-content` then controls vertical distribution while `align-items` handles horizontal. `flex-wrap: wrap` allows items onto multiple lines; `align-content` then controls spacing between those lines, which is a frequent source of confusion with `align-items`.

## Fitting, growing, and equal heights

The `flex` shorthand controls how items share free space: `flex: 1` means grow and shrink from a zero basis, `flex: 0 0 200px` means a fixed 200px item that neither grows nor shrinks. `flex: 1 1 220px` is the friendly middle ground for card grids.

Because flex items stretch to the tallest item in the row by default, equal-height cards come for free. Inside each card, `display: flex; flex-direction: column` plus `margin-top: auto` on the action button pins every button to the same baseline, regardless of copy length. The same technique makes a variable-height footer stick to the bottom of a column, and combining three vertical regions — header, expanding body, footer — is the classic sticky-footer pattern. For a holy-grail layout, make the page a column flex container, then make the middle row a flex row with fixed-width rails and a fluid centre.
