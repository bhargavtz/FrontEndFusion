# Set

A `Set` is a collection of unique values. It remembers insertion order, ignores duplicates automatically, and provides methods that make membership questions cheap. If you have ever built a list of names and then written an extra check to avoid adding the same name twice, a set removes that bookkeeping. Sets work with any data type, including objects, and compare values using same-value equality.

## Creating and editing a set

You create one with `new Set()`, optionally passing an iterable to seed it. The `add()` method inserts a value and returns the set itself, so calls can be chained. `has()` reports whether a value is present, `delete()` removes one, `clear()` empties the whole set, and the `size` property gives the current count. Because `add()` silently ignores a value that already exists, de-duplicating an array is as short as spreading a set built from it.

```js
const tags = new Set(["js", "css"]);
tags.add("js");        // still two items
tags.add("html");
tags.has("css");       // true
tags.size;             // 3
tags.delete("css");    // true
```

## Combining and iterating

Sets do not have built-in union or intersection methods, but the operations are easy to express. Convert a set to an array with `Array.from(set)` or the spread syntax, then use `filter()` together with `has()` to compute an intersection or a difference. Iteration is equally direct: `for...of` walks values in insertion order, and the `forEach()` method visits each one. The `keys()`, `values()`, and `entries()` methods exist for consistency with `Map`, though for a set both keys and values are the same.

The demo below is a tag manager. Add tags to see duplicates rejected, click a chip to remove it, and compare your tags against a built-in popular set.

```html
<!doctype html>
<html lang="en">

    <div class="card">

        <input id="tagInput" placeholder="e.g. javascript" />

      var tags = new Set();
      var popular = new Set(["javascript", "html", "css", "react"]);
      var chips = document.getElementById("chips");
      var out = document.getElementById("out");
      function render() {
        chips.textContent = "";
        tags.forEach(function (t) {
          var chip = document.createElement("span");
          chip.className = "chip";
          chip.textContent = t + "  x";
          chip.onclick = function () { tags.delete(t); render(); };

      document.getElementById("add").onclick = function () {
        var input = document.getElementById("tagInput");
        var value = input.value.trim().toLowerCase();
        if (!value) return;
        var before = tags.size;
        tags.add(value);
        out.textContent = tags.size > before
          ? "Added '" + value + "'."
          : "'" + value + "' was already present (duplicates ignored).";
        input.value = "";
        render();
      };
      document.getElementById("compare").onclick = function () {
        var arr = Array.from(tags);
        var shared = arr.filter(function (t) { return popular.has(t); });
        var unique = arr.filter(function (t) { return !popular.has(t); });
        out.textContent = "In common: " + (shared.join(", ") || "none") +
          "\nOnly yours: " + (unique.join(", ") || "none");
      };
      document.getElementById("clear").onclick = function () { tags.clear(); render(); };
      render();
    </script>
  </body>
```

Notice that the "Compare" button rebuilds arrays with `Array.from()` before filtering; that is the bridge between set membership and array transformations.
