# Context (this)

The value of `this` is not fixed where a function is written. It is decided when the function runs, largely by how the call is made. Grasping that single idea removes much of the mystery around method calls and callbacks.

## The call site decides

When a function is called as a method, `this` is the object before the dot. Calling the same body with `call()` or `apply()` lets you choose the object explicitly, which is useful for borrowing a method from one object and using it with another.

Detach the method into a plain variable and call it on its own, and that receiver disappears. In strict mode `this` becomes `undefined`; outside strict mode it falls back to the global object. This is why passing a method directly as an event handler often needs extra care.

## Saving, binding, and arrows

Older code captured the outer value in a variable, commonly named `self` or `that`, then used it inside a nested function. The `bind()` method offers a cleaner answer: it returns a new function permanently tied to the object you pass in.

Arrow functions take a different route. They have no `this` of their own and instead capture it from the surrounding scope, which makes them excellent for nested callbacks inside methods. Constructors are another case: with `new`, `this` points at the freshly created instance.

A frequent trap appears with timers and event listeners. Passing `obj.method` directly to `setTimeout` loses the receiver, so the callback sees the wrong `this`. Wrapping it in an arrow function, or binding it in advance, preserves the object you meant to use.

  "use strict";

  var robot = {
    name: "R2",
    identify: function () {
      return "I am " + ((this && this.name) || "nobody");
    },
    lexical: function () {
      var arrow = () => "the arrow inside me says " + this.name;
      return arrow();

    line("borrowed with call:  " + robot.identify.call(other));
    line("detached function:   " + detached());
    line("bound function:      " + bound());
    line("arrow inside method: " + robot.lexical());
    line("constructor call:    " + new Bot("T1000").identify());
  });
