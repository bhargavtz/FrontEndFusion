# Namespacing

A namespace is simply an object used as a container. Instead of scattering dozens of names across the global scope, you create one well-chosen global and hang everything else from it. Other scripts can then coexist without silently overwriting your helpers.

## Why one global is enough

Browser scripts share the same global object. Two files that both declare `format()` will clash, and the later definition wins. Wrapping your code in a single object such as `var App = App || {};` avoids that: you add `App.format` instead of a bare `format`, and the original value is preserved if another part of the app already created the container.

The `|| {}` pattern is important. It reuses an existing namespace rather than replacing it, which lets separate files contribute to the same container in any load order.

## Nesting related modules

Large namespaces benefit from sub-objects. An application might keep string helpers in `App.text`, drawing code in `App.ui`, and network logic in `App.data`. Each group stays small and discoverable, and a reader can see where a function belongs from its name alone.

Nested namespaces also make alias tricks easy. You can copy a deeply buried helper into a short local variable at the top of a function, keeping call sites readable while the public structure stays organized.

A namespace also gives you a natural place for constants and configuration. Instead of magic values sprinkled through a file, group them under `App.config` and change them in one spot. Keep the top level small: a handful of well-named modules is easier to navigate than a deep tree of single-function folders.

  <h2>Dashboard toolkit</h2>

<script>
  var Fusion = Fusion || {};

  Fusion.text = {
    upper: function (s) { return s.toUpperCase(); },
    title: function (s) {
      return s.replace(/[a-z]/g, function (c, i, all) {
        return i === 0 || all.charAt(i - 1) === " " ? c.toUpperCase() : c;
      });
    },
    reverse: function (s) { return s.split("").reverse().join(""); },
    count: function (s) { return s.trim() ? s.trim().split(" ").filter(Boolean).length : 0; }
  };

  Fusion.ui = {
    render: function (target, value) { target.textContent = value; }
  };

  var card = document.getElementById("card");
  var out = document.getElementById("out");

  document.querySelectorAll("button[data-op]").forEach(function (btn) {
    btn.addEventListener("click", function () {
      var op = btn.getAttribute("data-op");
      var value = document.getElementById("text").value;
      Fusion.ui.render(card, Fusion.text[op](value));
      out.textContent = "Called Fusion.text." + op + "() - only one global was added: Fusion";
    });
  });
</script>
