# Setters and Getters

Accessors are properties that run functions instead of holding raw data. Reading one calls a getter; assigning to one calls a setter. To the code using the object, the result looks exactly like a normal field, which makes accessors a clean way to add validation without changing the public interface.

## Accessors that look like fields

A getter can compute a value from other fields every time it is read. A setter can check a range, convert units, or refuse a bad value before anything is stored. The usual pattern pairs them with a backing field, often prefixed with an underscore, that holds the actual data.

Because the interface stays a simple property, you can replace stored data with computed data later without rewriting callers. That is the main appeal: accessors add behavior now and keep the door open for changes later.

## Three ways to define them

Inside an object literal, write `get name()` and `set name(value)` as method-like entries. With `Object.defineProperty()`, pass a descriptor containing `get` and `set` functions; you can also control `enumerable` and `configurable` there. ES6 classes support the same `get` and `set` prefixes inside the class body.

All three forms create accessor properties rather than data properties. A setter that receives a string where a number is expected should either coerce it or raise an error, since silent bad data is harder to debug than an immediate failure.

Accessors work with destructuring and spread too, though the exact behavior differs. Spreading an object reads its enumerable own properties, which invokes getters and produces plain values in the copy. If you need live accessor behavior, keep the original object rather than spreading it into a new one.

<script>
  var sensor = { _celsius: 20 };

  Object.defineProperty(sensor, "celsius", {
    get: function () { return this._celsius; },
    set: function (value) {
      var n = Number(value);
      if (!isFinite(n)) { throw new Error("Celsius must be a number"); }
      this._celsius = Math.max(-273.15, n);
    },
    enumerable: true
  });

  Object.defineProperty(sensor, "fahrenheit", {
    get: function () { return this.celsius * 9 / 5 + 32; },
    set: function (f) { this.celsius = (f - 32) * 5 / 9; },
    enumerable: true
  });

  class Thermometer {
    constructor(c) { this.celsius = c; }
    get celsius() { return this._c; }
    set celsius(value) { this._c = Math.max(-273.15, Number(value)); }
    get fahrenheit() { return this.celsius * 9 / 5 + 32; }
    set fahrenheit(f) { this.celsius = (f - 32) * 5 / 9; }
  }

  var therm = new Thermometer(20);
  var out = document.getElementById("out");
  var slider = document.getElementById("slider");

  function update(value) {
    sensor.celsius = value;
    therm.celsius = value;
    document.getElementById("cLabel").textContent = value;
    document.getElementById("a").textContent = sensor.fahrenheit.toFixed(1) + " F";
    document.getElementById("b").textContent = therm.fahrenheit.toFixed(1) + " F";
    out.textContent = "Stored celsius: " + sensor.celsius + " - fahrenheit was computed by a getter, never stored.";
  }

  slider.addEventListener("input", function () { update(Number(slider.value)); });

  document.querySelectorAll("button[data-c]").forEach(function (btn) {
    btn.addEventListener("click", function () {
      var value = Number(btn.getAttribute("data-c"));
      slider.value = value;
      update(value);
    });
  });

  document.getElementById("invalid").addEventListener("click", function () {
    try {
      sensor.celsius = "not a number";
    } catch (err) {
      out.textContent = "Setter rejected the write: " + err.message + " The stored value stayed at " + sensor.celsius + ".";
    }
  });

  update(20);
</script>
