# Async Iterators

A regular iterator produces values synchronously, one `next` call at a time. An async iterator does the same job when each value arrives later, returning a promise that resolves to an object with `value` and `done` fields. This makes it possible to walk over data that is fetched, streamed, or generated over time without manually juggling chained promises.

## Basics

An object becomes async-iterable by defining a method at the `Symbol.asyncIterator` key that returns the iterator. The easiest way to create one is with an async generator: a function declared with `async function*` can use `yield` to produce values and `await` to pause between them. Its `next` method then returns a promise for each result.

You consume such a source with the `for await` loop, which pauses at each step until the next value is ready. The loop ends when the generator finishes, and a `try` and `catch` block around it handles any error the source throws. This pattern is the foundation behind streaming responses and paginated APIs.

## Walking an async generator

The demo defines an async generator that yields simulated page results with a short delay between each. Pressing start consumes it with a `for await` loop and appends each value to the output as it arrives. A stop control cancels the run by flipping a flag, showing that you can break out of an async loop just like a normal one.

      var out = document.getElementById("out");
      var lines = [];
      var running = false;
      function log(text) {
        lines.push(text);
        if (lines.length > 9) lines.shift();
        out.textContent = lines.join("\n");
      }
      function wait(ms) {
        return new Promise(function (resolve) { window.setTimeout(resolve, ms); });
      }
      async function* pages() {
        for (var n = 1; n <= 6; n++) {
          await wait(450);
          yield { page: n, title: "Article batch " + n };

      document.getElementById("start").addEventListener("click", async function () {
        if (running) return;
        running = true;
        lines = [];
        log("for await loop started");
        for await (var item of pages()) {
          if (!running) break;
          log("yielded -> page " + item.page + ": " + item.title);
        }
        log(running ? "stream finished (done = true)" : "stream stopped by user");
        running = false;
      });
      document.getElementById("stop").addEventListener("click", function () {
        if (running) { running = false; log("stop requested…"); }
      });
