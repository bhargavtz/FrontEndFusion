# JavaScript Basics

This is the starting point for the 101-chapter JavaScript reference. Instead of reading a wall of syntax, you will build a small interactive task board in five steps. Each step has a checkpoint, a runnable demo, and a link to the deeper chapter.

> **Full reference:** after this quickstart, continue with the [complete 101-chapter JavaScript reference](#complete-javascript-reference) at the bottom, or jump straight to [Getting Started with JavaScript](/docs/js-getting-started-with-javascript).

## What you'll build

A tiny task board that can add tasks, mark them done, filter them, and load a starter list from a mock API.

| | |
|---|---|
| **Time** | 20–30 minutes |
| **Level** | Beginner |
| **Prerequisites** | A browser and a code editor |

By the end you will be able to:

- read and change the page with the DOM
- store values in variables and template literals
- write functions and handle click events
- work with arrays and objects
- load data asynchronously with `fetch` and `async`/`await`

## Step 1 — See a result

Start with the smallest possible win: write a value into the page. The `document.querySelector()` call finds an element, and `textContent` replaces its contents.

```html
<div class="card">
  <h2>Step 1: output</h2>
  <p id="out">Waiting for JavaScript…</p>
  <button id="run">Run the code</button>
</div>

<style>
  body { margin: 0; padding: 24px; font-family: system-ui, sans-serif; background: #f4f6fb; color: #172033; }
  .card { max-width: 420px; padding: 24px; border-radius: 18px; background: #fff; box-shadow: 0 18px 40px -24px rgba(23, 32, 51, .45); }
  button { border: 0; border-radius: 10px; padding: 10px 16px; background: #2563eb; color: #fff; font-weight: 700; cursor: pointer; }
</style>

<script>
  const out = document.getElementById("out");
  document.getElementById("run").addEventListener("click", () => {
    const name = "Mira";
    const count = 3;
    out.textContent = `Hello ${name}, you have ${count} tasks today.`;
  });
</script>
```

**Checkpoint:** click **Run the code** and you should see a personalised sentence. If nothing happens, check the console for a red error.

Variables store values. Prefer `const` until you need to reassign with `let`; avoid `var` in new code.

```js
const name = "Mira";   // cannot be reassigned
let count = 3;         // can be reassigned
count = count + 1;
```

Template literals use backticks and `${…}` to insert values without string concatenation.

```js
const message = `Hello ${name}, you have ${count} tasks.`;
```

## Step 2 — Add behaviour with functions and events

A function packages a piece of behaviour. An event listener runs that function when the user does something.

```html
<div class="card">
  <h2>Step 2: a counter</h2>
  <p class="value" id="value">0</p>
  <div class="row">
    <button id="minus" aria-label="Decrease">−</button>
    <button id="plus" aria-label="Increase">+</button>
  </div>
</div>

<style>
  body { margin: 0; padding: 24px; font-family: system-ui, sans-serif; background: #f4f6fb; color: #172033; }
  .card { max-width: 420px; padding: 24px; border-radius: 18px; background: #fff; box-shadow: 0 18px 40px -24px rgba(23, 32, 51, .45); }
  .value { font-size: 3rem; font-weight: 800; margin: 8px 0 16px; color: #2563eb; }
  .row { display: flex; gap: 10px; }
  button { border: 0; border-radius: 10px; padding: 10px 18px; background: #e8eefc; color: #1d4ed8; font-size: 1.1rem; font-weight: 800; cursor: pointer; }
</style>

<script>
  let count = 0;
  const value = document.getElementById("value");

  function render() {
    value.textContent = String(count);
  }

  document.getElementById("plus").addEventListener("click", () => {
    count += 1;
    render();
  });

  document.getElementById("minus").addEventListener("click", () => {
    if (count > 0) count -= 1;
    render();
  });
</script>
```

**Checkpoint:** the plus button increments, and the minus button never goes below zero. The guard `if (count > 0)` is a simple form of validation.

## Step 3 — Store data in arrays and objects

A task has several fields, so an object fits. A list of tasks is an array of those objects.

```html
<div class="card">
  <h2>Step 3: render a list</h2>
  <ul id="list" class="list"></ul>
</div>

<style>
  body { margin: 0; padding: 24px; font-family: system-ui, sans-serif; background: #f4f6fb; color: #172033; }
  .card { max-width: 460px; padding: 24px; border-radius: 18px; background: #fff; box-shadow: 0 18px 40px -24px rgba(23, 32, 51, .45); }
  .list { list-style: none; margin: 0; padding: 0; display: grid; gap: 10px; }
  .list li { display: flex; justify-content: space-between; gap: 12px; padding: 12px 14px; border-radius: 12px; background: #f1f5ff; }
  .done { color: #64748b; text-decoration: line-through; }
</style>

<script>
  const tasks = [
    { id: 1, title: "Read the DOM chapter", done: true },
    { id: 2, title: "Build the counter", done: true },
    { id: 3, title: "Render a task list", done: false },
  ];

  const list = document.getElementById("list");
  list.innerHTML = "";

  for (const task of tasks) {
    const item = document.createElement("li");
    item.innerHTML = `<span class="${task.done ? "done" : ""}">${task.title}</span><span>${task.done ? "✓" : "○"}</span>`;
    list.appendChild(item);
  }
</script>
```

**Checkpoint:** three rows appear, and the completed ones are crossed out.

Use `map()` when you want a new array, `filter()` when you want a subset, and `find()` when you want one item.

```js
const open = tasks.filter((task) => !task.done);
const first = tasks.find((task) => task.id === 3);
const titles = tasks.map((task) => task.title);
```

## Step 4 — Make it interactive

Now combine state, events, and rendering. Keep a single `tasks` array as the source of truth, change it, then re-render.

```html
<div class="card">
  <h2>Step 4: add and complete tasks</h2>
  <form id="form">
    <input id="input" placeholder="New task…" autocomplete="off" />
    <button type="submit">Add</button>
  </form>
  <div class="filters">
    <button data-filter="all" class="active">All</button>
    <button data-filter="open">Open</button>
    <button data-filter="done">Done</button>
  </div>
  <ul id="list" class="list"></ul>
</div>

<style>
  body { margin: 0; padding: 24px; font-family: system-ui, sans-serif; background: #f4f6fb; color: #172033; }
  .card { max-width: 500px; padding: 24px; border-radius: 18px; background: #fff; box-shadow: 0 18px 40px -24px rgba(23, 32, 51, .45); }
  form { display: flex; gap: 8px; }
  input { flex: 1; border: 1px solid #cbd5e1; border-radius: 10px; padding: 10px 12px; font: inherit; }
  form button { border: 0; border-radius: 10px; padding: 10px 16px; background: #2563eb; color: #fff; font-weight: 700; cursor: pointer; }
  .filters { display: flex; gap: 6px; margin: 14px 0; }
  .filters button { border: 1px solid #cbd5e1; border-radius: 999px; padding: 5px 12px; background: #fff; cursor: pointer; }
  .filters button.active { background: #172033; border-color: #172033; color: #fff; }
  .list { list-style: none; margin: 0; padding: 0; display: grid; gap: 8px; }
  .list li { display: flex; align-items: center; gap: 10px; padding: 10px 12px; border-radius: 10px; background: #f1f5ff; }
  .list li.done span { color: #64748b; text-decoration: line-through; }
  .list input { flex: 0 0 auto; }
</style>

<script>
  let tasks = [
    { id: 1, title: "Read the DOM chapter", done: true },
    { id: 2, title: "Build the counter", done: true },
  ];
  let filter = "all";

  const list = document.getElementById("list");
  const input = document.getElementById("input");
  const form = document.getElementById("form");

  function visibleTasks() {
    if (filter === "open") return tasks.filter((task) => !task.done);
    if (filter === "done") return tasks.filter((task) => task.done);
    return tasks;
  }

  function render() {
    list.innerHTML = "";
    for (const task of visibleTasks()) {
      const li = document.createElement("li");
      li.className = task.done ? "done" : "";
      const box = document.createElement("input");
      box.type = "checkbox";
      box.checked = task.done;
      box.addEventListener("change", () => {
        task.done = box.checked;
        render();
      });
      const label = document.createElement("span");
      label.textContent = task.title;
      li.append(box, label);
      list.appendChild(li);
    }
  }

  form.addEventListener("submit", (event) => {
    event.preventDefault();
    const title = input.value.trim();
    if (!title) return;
    tasks.push({ id: Date.now(), title, done: false });
    input.value = "";
    render();
  });

  document.querySelectorAll("[data-filter]").forEach((button) => {
    button.addEventListener("click", () => {
      filter = button.dataset.filter;
      document.querySelectorAll("[data-filter]").forEach((b) => b.classList.toggle("active", b === button));
      render();
    });
  });

  render();
</script>
```

**Checkpoint:** add a task, tick it off, and switch between the filters. The list should update instantly.

## Step 5 — Load data asynchronously

Real apps fetch data instead of hard-coding it. `fetch()` returns a promise, and `async`/`await` lets you read it top to bottom.

```html
<div class="card">
  <h2>Step 5: async loading</h2>
  <button id="load">Load starter tasks</button>
  <p id="status" class="status">No data yet.</p>
  <ul id="list" class="list"></ul>
</div>

<style>
  body { margin: 0; padding: 24px; font-family: system-ui, sans-serif; background: #f4f6fb; color: #172033; }
  .card { max-width: 460px; padding: 24px; border-radius: 18px; background: #fff; box-shadow: 0 18px 40px -24px rgba(23, 32, 51, .45); }
  button { border: 0; border-radius: 10px; padding: 10px 16px; background: #2563eb; color: #fff; font-weight: 700; cursor: pointer; }
  .status { color: #64748b; font-size: .9rem; }
  .list { list-style: none; margin: 12px 0 0; padding: 0; display: grid; gap: 8px; }
  .list li { padding: 10px 12px; border-radius: 10px; background: #f1f5ff; }
</style>

<script>
  const status = document.getElementById("status");
  const list = document.getElementById("list");

  // A mock API so the demo works offline. The async pattern is the real lesson.
  function mockFetch() {
    return new Promise((resolve) => {
      setTimeout(() => {
        resolve({
          ok: true,
          json: async () => [
            { id: 1, title: "Read the async chapter" },
            { id: 2, title: "Try a promise" },
            { id: 3, title: "Load data in the UI" },
          ],
        });
      }, 700);
    });
  }

  async function loadTasks() {
    status.textContent = "Loading…";
    list.innerHTML = "";
    try {
      const response = await mockFetch();
      if (!response.ok) throw new Error("Request failed");
      const tasks = await response.json();
      for (const task of tasks) {
        const li = document.createElement("li");
        li.textContent = task.title;
        list.appendChild(li);
      }
      status.textContent = `Loaded ${tasks.length} tasks.`;
    } catch (error) {
      status.textContent = `Something went wrong: ${error.message}`;
    }
  }

  document.getElementById("load").addEventListener("click", loadTasks);
</script>
```

**Checkpoint:** click **Load starter tasks**. The status changes to “Loading…”, then the list appears after a short delay. If the request fails, the `catch` block shows a readable message.

## Troubleshooting

### “Cannot read properties of null”

`querySelector()` returned `null` because the element was not found. Check the `id` or class name, and make sure the script runs after the element exists.

```js
const button = document.querySelector("#save");
if (!button) {
  console.warn("No #save button on this page");
}
```

### The click handler does nothing

- Confirm the selector matches exactly one element.
- Check the browser console for an error before the listener was attached.
- Make sure the script is after the markup, or wrapped in `DOMContentLoaded`.

### “Unexpected token” or “missing ) after argument list”

A bracket, quote, or backtick is unbalanced. Look at the line number in the console and count the opening and closing pairs.

### `fetch` fails in the preview

The live preview runs in a sandboxed iframe. Network requests may be blocked. Use the mock pattern shown in step 5, or run the example in a normal page.

## What you learned

- find elements with `querySelector` and change them with `textContent`
- store values with `const` and `let`
- package behaviour in functions and attach it with `addEventListener`
- model data with arrays of objects and render it with `map`/`for…of`
- handle asynchronous work with `async`/`await` and `try`/`catch`
