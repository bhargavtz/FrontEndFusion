# Linking Resources

The `link` element declares a relationship between the current document and another resource. It belongs in the document head.

## JavaScript

Historically, scripts were sometimes linked with `link`, but the correct element is `script`.

```html
<script src="/js/app.js" defer></script>
```

Use `defer` for scripts that should run after the document is parsed. Use `async` for independent scripts that can run as soon as they download.

## External CSS stylesheet

```html
<link rel="stylesheet" href="/css/main.css" />
```

Place stylesheets in the head so the first paint uses the final styles. A stylesheet in the body can cause a flash of unstyled content.

## Favicon

```html
<link rel="icon" href="/favicon.ico" sizes="any" />
<link rel="icon" href="/favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />
```

Provide at least one icon. SVG icons scale cleanly; the `.ico` file remains a useful fallback.

## Alternative stylesheets

```html
<link rel="stylesheet" href="/css/main.css" title="Default" />
<link rel="alternate stylesheet" href="/css/high-contrast.css" title="High contrast" />
```

Alternative stylesheets are disabled until the user selects them. Modern sites often provide a theme switch instead.

## Resource hints

```html
<link rel="dns-prefetch" href="//fonts.example.com" />
<link rel="preconnect" href="https://fonts.example.com" crossorigin />
<link rel="prefetch" href="/next-page.html" as="document" />
<link rel="prerender" href="/likely-next-page.html" />
```

- `dns-prefetch` resolves a domain early.
- `preconnect` also opens the connection.
- `prefetch` downloads a resource for a future navigation.
- `prerender` asks the browser to render a page in the background.

Use these sparingly. Overusing them competes with the current page's resources.

## The media attribute

```html
<link rel="stylesheet" href="/css/print.css" media="print" />
<link rel="stylesheet" href="/css/mobile.css" media="(max-width: 600px)" />
```

The browser downloads the file but only applies it when the media condition matches.

## Previous and next links

```html
<link rel="prev" href="/html5/doctypes" />
<link rel="next" href="/html5/headings" />
```

These hints describe a sequence of documents. Search engines may use them to understand pagination.

## Web feed

```html
<link
  rel="alternate"
  type="application/rss+xml"
  title="FrontEndFusion updates"
  href="/feed.xml"
/>
```

RSS and Atom feeds let readers and feed services subscribe to new content.

## Checklist

1. Put resource links in the head.
2. Use `rel` values that describe the real relationship.
3. Provide a favicon.
4. Do not preload everything; prioritise the critical path.
