# Declarations and Assignments

Before you can use a value, you usually give it a name. JavaScript offers several ways to declare a name, and several operators to change the value it holds.

## let, const, and var

`let` declares a block-scoped variable that you can reassign later. `const` also has block scope but fixes the binding after its initial assignment, which is a good default for values that should not be swapped out. Note that `const` prevents reassignment of the binding, not mutation of the object it points to. Older code often uses `var`, which is function-scoped rather than block-scoped and can be declared again without error; its quirks are why `let` and `const` are preferred today. A variable declared but never given a value holds `undefined`.

## Assignment and compound operators

The single `=` operator stores the value on its right into the name on its left. Compound operators combine an operation with an assignment: `+=` adds, `-=` subtracts, `*=` multiplies, `/=` divides, and `%=` stores the remainder. They are shorter and clearer than repeating the variable name. The `++` and `--` operators increment or decrement by one; placing them before or after the name changes whether the old or new value is used in the surrounding expression. Assignment expressions evaluate to the value assigned, so chains such as `a = b = 0` set both names.

## Demo: scoreboard

The demo keeps a score in a `let` variable and a fixed step in a `const`. Buttons apply compound assignments and show the result.

```html
<div class="wrap">
  <div class="card">
    <h2>Scoreboard</h2>
    <p class="hint">A constant step and a mutable score, updated with compound operators.</p>
    <div class="score" id="score">0</div>
    <div class="row">
      <button data-op="add">+ step</button>
      <button data-op="sub">− step</button>
      <button data-op="double">× 2</button>
      <button data-op="reset" class="alt">Reset</button>
    </div>
    <pre class="out" id="out"></pre>
  </div>
</div>

<script>
  const STEP = 5;
  let score = 0;
  let lastAction = "start";
  let notSet;

  function render() {
    document.getElementById("score").textContent = score;
    document.getElementById("out").textContent =
      "Step (const): " + STEP + "\n" +
      "Score (let): " + score + "\n" +
      "Last action: " + lastAction + "\n" +
      "Unassigned variable: " + String(notSet);
  }

  Array.prototype.forEach.call(document.querySelectorAll("button[data-op]"), function (btn) {
    btn.addEventListener("click", function () {
      var op = btn.dataset.op;
      if (op === "add") { score += STEP; lastAction = "score += STEP"; }
      if (op === "sub") { score -= STEP; lastAction = "score -= STEP"; }
      if (op === "double") { score *= 2; lastAction = "score *= 2"; }
      if (op === "reset") { score = 0; lastAction = "score = 0"; }
      render();
    });
  });
  render();
</script>
```
