# Transpiling

JavaScript evolves faster than browsers update. Transpiling takes source written with newer syntax and rewrites it into equivalent code that older engines can parse. The output behaves the same way, but it uses constructs from an earlier version of the language.

## Why transpile

Newer features such as arrow functions, classes, template literals, and `let` and `const` are convenient, yet a user may run an older browser that does not parse them. A transpiler runs during the build, so the shipped code works broadly while developers keep writing modern syntax. Note that syntax can be translated, but brand-new built-in methods usually need a polyfill instead.

A typical setup uses Babel. You install it as a development dependency, add a small configuration describing which environments to target, and run it over your source folder. Modern tooling chains Babel into bundlers so the conversion happens automatically on every build. Targets are usually expressed as browser queries, which lets the tool emit only the transformations that are actually needed.

## What the rewrite looks like

An arrow function becomes a normal `function` expression, with `this` handled carefully. Template literals become string concatenation. A class becomes a constructor function plus assignments to its prototype. The demo performs a simplified version of these rewrites on a few sample snippets and shows the before and after side by side, which makes the idea concrete even without installing anything.

<html lang="en">
  <head>

    <title>Transpiling</title>
    <style>
      body {
        margin: 0;

        color: #2b2a33;

      }
      .card {
        max-width: 560px;
        margin: 0 auto;
        padding: 22px;
        background: #fff;
        border-radius: 20px;
        box-shadow: 0 20px 42px -30px rgba(80, 50, 30, 0.45);
      }
      h1 { margin: 0 0 14px; font-size: 1.15rem; }
      .row { display: flex; flex-wrap: wrap; gap: 8px; margin-bottom: 14px; }

    <div class="card">
      <h1>Mini transpiler</h1>
      <div class="row">
        <button class="sample active" data-i="0">Arrow function</button>
        <button class="sample" data-i="1">Template literal</button>
        <button class="sample" data-i="2">let / const</button>
      </div>
      <div class="panes">
        <div class="pane"><h2>Modern source</h2><pre id="src"></pre></div>

      </div>
    </div>
    <script>
      var samples = [
        {
          src: "const add = (a, b) => a + b;",
          out: "var add = function (a, b) { return a + b; };"
        },
        {
          src: "const msg = `Hello ${name}, you have ${n} points`;",
          out: "var msg = 'Hello ' + name + ', you have ' + n + ' points';"
        },
        {
          src: "let count = 0;\nconst limit = 10;",
          out: "var count = 0;\nvar limit = 10;"
        }
      ];
      function show(i) {
        document.getElementById("src").textContent = samples[i].src;
        document.getElementById("dst").textContent = samples[i].out;
      }
      document.querySelectorAll(".sample").forEach(function (btn) {
        btn.addEventListener("click", function () {
          document.querySelectorAll(".sample").forEach(function (b) { b.classList.remove("active"); });
          btn.classList.add("active");
          show(Number(btn.dataset.i));
        });
      });
      show(0);
    </script>
  </body>
