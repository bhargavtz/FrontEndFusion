# Data Manipulation

A large share of day-to-day JavaScript is reshaping values: turning a number into money, pulling a piece out of a string, or writing a property whose name you only know at runtime. These small transformations come up in forms, reports, and API glue code. The standard library covers most of them without any external package.

## Formatting numbers as money

`Intl.NumberFormat` localises numeric output. Give it a locale and an options object with `style: "currency"` and a `currency` code, and its `format()` method returns a correctly grouped, symbol-prefixed string. Unlike manual string concatenation, it handles decimals, separators, and placement rules for each locale.

```js
const usd = new Intl.NumberFormat("en-US", {
  style: "currency", currency: "USD"
});
usd.format(1234.5); // "$1,234.50"
```

## Strings and dynamic properties

To find a file extension, locate the last dot with `lastIndexOf(".")` and slice after it. Guard against a missing dot and against dotfiles so a name like `.env` does not report `env` as an extension. For dynamic properties, square-bracket notation evaluates the expression inside the brackets, so `obj[key]` reads or writes the property named by `key`. Dot notation cannot do this. When the key contains dots representing a path, split it and walk the object one level at a time, creating intermediate objects as needed.

```js
function setPath(obj, path, value) {
  const parts = path.split(".");
  let ref = obj;
  parts.forEach((part, i) => {
    if (i === parts.length - 1) ref[part] = value;
    else ref = ref[part] || (ref[part] = {});
  });
}
```
