# Functions

A function bundles a set of statements under a name so you can run them repeatedly with different inputs. Functions are values in JavaScript, which means you can store them, pass them around, and return them.

## Ways to declare a function

A function declaration uses the `function` keyword followed by a name and a parameter list. A function expression assigns an anonymous or named function to a variable, and the arrow syntax `=>` is a compact form that also changes how `this` is bound. Immediately invoked function expressions, or IIFEs, are functions that run as soon as they are defined; they were a common way to create private scope before modules existed.

## Parameters and arguments

Parameters are the names in a declaration; arguments are the values passed at a call site. Default parameters such as `function greet(name = "Guest")` supply a fallback when an argument is missing. Rest parameters written as `...items` collect any number of extra arguments into an array. The older `arguments` object is array-like but not a true array. Objects and arrays are passed by reference, so a function can change their contents, while primitive values are passed as copies.

## Return values, recursion, and scope

The `return` statement ends a function and hands a value back; without it, the result is `undefined`. A recursive function calls itself, which suits problems that break into smaller versions of themselves, provided there is a base case to stop. Variables declared inside a function are local to it, while closures let an inner function keep access to an outer function's scope after it has returned.

<script>
  function factorial(n) {
    if (n <= 1) { return 1; }
    return n * factorial(n - 1);
  }

  function greet(name = "Guest") {
    return "Hello, " + name + "!";
  }

  function sumAll(...numbers) {
    return numbers.reduce(function (a, b) { return a + b; }, 0);
  }

  var times = function (a) {
    return function (b) { return a * b; };
  };

  var started = (function () { return "IIFE ran once at load"; })();

  document.getElementById("run").addEventListener("click", function () {
    var raw = document.getElementById("n").value;
    var n = Math.max(0, Math.min(12, Number(raw) || 0));
    document.getElementById("out").textContent =
      "factorial(" + n + ") = " + factorial(n) + "\n" +
      "greet() = " + greet() + "\n" +
      "greet('Ada') = " + greet("Ada") + "\n" +
      "sumAll(2, 4, 6, 8) = " + sumAll(2, 4, 6, 8) + "\n" +
      "times(3)(7) = " + times(3)(7) + "\n" +
      started + "\n" +
      "function name: " + factorial.name;
  });
  document.getElementById("run").click();
