# Arithmetic (Math)

JavaScript can calculate as well as organize data. Basic arithmetic uses operators, while more advanced work is handled by the built-in `Math` object, which is a library of constants and functions rather than a value you create.

## Operators and precedence

The familiar operators apply: `+` adds, `-` subtracts, `*` multiplies, `/` divides, and `%` returns the remainder. Multiplication and division bind more tightly than addition, and parentheses override the order explicitly. The `**` operator raises a number to a power, while `++` and `--` increment or decrement a variable in place. A subtle point: adding a string to a number concatenates rather than sums, so convert with `Number()` when you mean arithmetic.

## The Math object

`Math.round` returns the nearest integer, `Math.floor` rounds down, and `Math.ceil` rounds up. `Math.max` and `Math.min` accept a list of numbers and return the largest or smallest; spread an array into them to compare its contents. `Math.abs` gives the absolute value, `Math.sqrt` the square root, and `Math.pow(base, exponent)` a power, though `**` is often shorter. The constant `Math.PI` holds the ratio of a circle's circumference to its diameter. `Math.hypot` computes the length of a vector from its components without manual squaring.

## Random numbers

`Math.random()` returns a floating-point value at least zero and below one. Multiply by a range and apply `Math.floor` to get a random integer: `Math.floor(Math.random() * 6) + 1` produces a die roll from one to six. For a number between a minimum and maximum, use `Math.floor(Math.random() * (max - min + 1)) + min`. Because the generator is pseudo-random and not cryptographically secure, use the Web Crypto API for anything security-related.

<script>
  function compute() {
    var r = Number(document.getElementById("radius").value);
    var out = document.getElementById("out");
    if (!Number.isFinite(r) || r < 0) {
      out.textContent = "Enter a valid, non-negative radius.";
      return;
    }
    var area = Math.PI * Math.pow(r, 2);
    var circumference = 2 * Math.PI * r;
    out.textContent =
      "Radius: " + r + "\n" +
      "Area: " + area.toFixed(2) + "\n" +
      "Circumference: " + circumference.toFixed(2) + "\n" +
      "Rounded area: " + Math.round(area) + "\n" +
      "Square root: " + Math.sqrt(r).toFixed(2) + "\n" +
      "Max of radius and 5: " + Math.max(r, 5) + "\n" +
      "Hypotenuse (r, r): " + Math.hypot(r, r).toFixed(2);
  }

  function roll() {
    var face = Math.floor(Math.random() * 6) + 1;
    document.getElementById("dice").textContent = face;
  }

  document.getElementById("compute").addEventListener("click", compute);
  document.getElementById("roll").addEventListener("click", roll);
  compute();
</script>
