# Constructor functions

When you need many objects with the same shape, a constructor function acts as a blueprint. Calling it with `new` produces a fresh object whose properties are set up by the function.

## Declaring a constructor

A constructor is an ordinary function, conventionally named with a capital letter. Inside it, `this` refers to the new object being built. Assign fields with `this.title = value` and so on. You do not return the object explicitly: `new` creates it, runs the function, and hands back the result. Calling the function without `new` skips that setup and can write to the global object, which is why the capital-letter convention matters.

```
function Book(title, author) {
  this.title = title;
  this.author = author;
}
```

## Prototype methods and instanceof

Methods placed on `Book.prototype` are shared by every instance instead of being recreated for each one. A call like `book.summary()` looks for the method on the object, then follows its prototype chain to find it on `Book.prototype`. The `instanceof` operator tests whether an object was built by a particular constructor, returning true when that constructor's prototype appears in the chain. Use `Object.create` or a class when you need a different setup, but the constructor pattern is still widely seen in older code and remains useful to understand.

## Demo: book shelf

The demo builds several books from one constructor, gives them a shared method, and verifies their origin with `instanceof`.

```html
<div class="wrap">
  <div class="card">
    <h2>Book shelf</h2>
    <p class="hint">Every card is an instance of the same constructor function.</p>
    <div class="shelf" id="shelf"></div>
    <pre class="out" id="out"></pre>
  </div>
</div>

<script>
  function Book(title, author, pages) {
    this.title = title;
    this.author = author;
    this.pages = pages;
  }

  Book.prototype.summary = function () {
    return this.title + " by " + this.author + " (" + this.pages + " pages)";
  };

  var books = [
    new Book("The Web Surface", "A. Rivera", 240),
    new Book("Signals and Slots", "M. Chen", 318),
    new Book("Small Systems", "L. Okafor", 176)
  ];

  var shelf = document.getElementById("shelf");
  books.forEach(function (book) {
    var row = document.createElement("div");
    row.className = "book";
    var title = document.createElement("strong");
    var detail = document.createElement("span");
    title.textContent = book.title;
    detail.textContent = book.summary();
    row.appendChild(title);
    row.appendChild(detail);
    shelf.appendChild(row);
  });

  document.getElementById("out").textContent =
    "All are Book instances: " + books.every(function (b) { return b instanceof Book; }) + "\n" +
    "summary lives on the prototype: " + (books[0].hasOwnProperty("summary") === false) + "\n" +
    "Constructed count: " + books.length;
</script>
```
