# Binary Data

JavaScript is not limited to text and objects. It can also handle raw bytes, which is what images, audio, file uploads, and network protocols are made of. The `ArrayBuffer` type is a fixed-length block of memory, and views layered on top of it let you interpret those bytes in structured ways.

## ArrayBuffer and TypedArrays

An `ArrayBuffer` is an opaque container; you cannot read it directly. You wrap it in a typed array such as `Uint8Array` for bytes or `Float64Array` for numbers. Every view points at the same memory, so changing one is visible through the others.

```js
const buffer = new ArrayBuffer(4);
const bytes = new Uint8Array(buffer); // four values, each 0-255
bytes[0] = 255;
```

Because the same bytes can mean different things, you must pay attention to byte order, known as endianness, when reading multi-byte numbers.

## DataView and byte manipulation

`DataView` gives explicit control that typed arrays hide. Methods like `setUint32()` and `getUint32()` take a byte offset plus a boolean flag choosing little-endian or big-endian layout. This makes it possible to parse binary file headers correctly on any device, instead of trusting the host machine's default order.

## Blob, Base64, and iteration

A `Blob` bundles raw data with a MIME type and is what a file input hands you. Convert a `Blob` to bytes with `blob.arrayBuffer()`, or build one from bytes with `new Blob([buffer])`. To carry bytes inside text you can decode a Base64 string into a `Uint8Array`. Any typed array supports a plain `for...of` loop, and `Array.from()` turns it into a regular array for methods like `map()`.

The inspector below writes RGBA bytes into one shared buffer while a `DataView` reads the very same bytes as 32-bit integers in both byte orders.

<script>
  const out = document.getElementById('out');
  const swatch = document.getElementById('swatch');
  function render(){
    const buffer = new ArrayBuffer(8);
    const bytes = new Uint8Array(buffer);
    const view = new DataView(buffer);
    const r = Number(document.getElementById('r').value);
    const g = Number(document.getElementById('g').value);
    const b = Number(document.getElementById('b').value);
    bytes[0] = r; bytes[1] = g; bytes[2] = b; bytes[3] = 255;

    document.getElementById(id).addEventListener('input', render);
  });
