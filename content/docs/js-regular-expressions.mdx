# Regular expressions

A regular expression is a compact language for describing text patterns. It can answer whether a string fits a shape, pull out pieces of it, or rewrite every match. JavaScript represents them with `RegExp` objects and with slash-delimited literals.

## Creating and matching patterns

A literal such as `/hello/i` is created when the code is parsed. Calling `new RegExp("hello", "i")` builds the same thing from strings at runtime, which is handy when the pattern comes from user input. The trailing `i` is a flag; others include `g` for a global search and `m` for multiline anchors.

The `test()` method returns a boolean, ideal for validation. The `exec()` method returns a match object with details, or `null` when nothing matched. With the global flag, repeated `exec()` calls walk through every match in the string.

## Flags, groups, and replacement

Parentheses create capture groups. Each group's text appears in the match array by position, so a pattern for key and value pairs can be taken apart after a single match.

`replace()` can accept a callback as its second argument. The function runs once per match and its return value becomes the replacement text, which allows logic based on what was found. Keep patterns specific: a broad expression that matches too much is a common source of confusing validation bugs.

Be careful with user-supplied patterns. A pattern that can match an enormous range of input may take a long time to evaluate, and text pasted into a pattern should be escaped before it is compiled. For fixed validation rules, literal patterns are both quicker to write and easier to audit.

<script>
  var patterns = {
    email: /^[^ @]+@[^ @]+[.][^ @]+$/,
    phone: /^[+-]?[0-9][0-9 -]{5,14}[0-9]$/,
    hex: /^#([0-9a-f]{3}|[0-9a-f]{6})$/i
  };

  var out = document.getElementById("out");

  function validate() {
    var lines = [];
    document.querySelectorAll("input[data-pattern]").forEach(function (input) {
      var key = input.getAttribute("data-pattern");
      var ok = patterns[key].test(input.value);
      var field = input.closest(".field");
      field.classList.toggle("good", ok);
      field.classList.toggle("bad", !ok);
      field.querySelector(".status").textContent = ok ? "match" : "no match";
      lines.push(key + ": " + (ok ? "valid" : "invalid"));
    });
    out.textContent = lines.join("\n");
  }

  document.querySelectorAll("input[data-pattern]").forEach(function (input) {
    input.addEventListener("input", validate);
  });

  document.getElementById("highlight").addEventListener("click", function () {
    var text = "Mail ada@example.com or call +1 555 123 4567. The accent is #2f7fb5.";
    var finder = /[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+[.][A-Za-z]{2,}|#[0-9a-f]{6}/gi;
    var marked = text.replace(finder, function (match) { return "[" + match + "]"; });
    out.textContent = "replace() with a callback:\n" + marked;
  });

  document.getElementById("extract").addEventListener("click", function () {
    var source = "alpha=12, beta=34, alpha=56";
    var pair = /(alpha|beta)=([0-9]+)/g;
    var match;
    var lines = [];
    while ((match = pair.exec(source)) !== null) {
      lines.push("key " + match[1] + " -> value " + match[2]);
    }
    out.textContent = "exec() with capture groups:\n" + lines.join("\n");
  });

  validate();
</script>
