# Length Units

A length is a number plus a unit, and the unit decides what the number is measured against. Choosing well means a layout survives zoom, user font settings, and a phone screen without a rewrite.

## Absolute and relative units

`px` is the familiar absolute unit: one CSS pixel, which is not a physical pixel on a high-density display. Other absolute units — `cm`, `mm`, `in`, `pt` — exist mainly for print. Absolute lengths do not respond to the user's preferred font size, so using them for body text is an accessibility risk.

Relative units inherit their meaning from context. `%` resolves against a parent's dimension, and which dimension depends on the property: width percentages use the parent width, while vertical padding and margins also use the parent width, which explains some surprising results. `em` resolves against the current element's font size, so nested `em` values compound. `rem` always resolves against the root font size, making it predictable for spacing and type.

## rem and em in practice

Set the root size in `rem` or leave it alone, size body copy in `rem`, and let the browser's default remain a user preference rather than a fixed value. Use `rem` for component spacing so an entire UI scales when the root changes.

Use `em` deliberately for values that should scale with their own component — padding inside a button that grows with its label, or a media-query-like breakpoint derived from text. The compounding behaviour is a feature there, and a bug when applied carelessly to nested lists.

## Viewport units and percentages

`vw` and `vh` are percentages of the viewport's width and height. `vmin` and `vmax` refer to the smaller and larger dimension, which is how you build a square that always fits: `width: 40vmin; height: 40vmin`. Viewport units are ideal for full-bleed hero sections, but mobile browser chrome can make `vh` jump; `dvh`, `svh`, and `lvh` address that by describing dynamic, small, and large viewport heights.

Percentages are best for proportional relationships inside a known container: a progress bar at `72%`, or a two-column split. They fail silently when the parent has no defined size, so combine them with a container that has one.
