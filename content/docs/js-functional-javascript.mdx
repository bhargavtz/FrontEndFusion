# Functional JavaScript

Functional programming treats computation as the evaluation of functions while avoiding shared state and mutable data. JavaScript supports this style because functions are first-class values you can pass around and combine.

## Pure functions

A pure function depends only on its inputs and returns the same result for the same arguments every time. It has no side effects: it does not change outside variables, mutate its parameters, or write to the DOM. For example, a function that doubles a number is pure, while one that increments a global counter is not. Purity makes code easier to test and reason about because behavior is local and predictable. When you need to change data, create a copy instead of editing the original.

## Higher-order functions

A higher-order function either accepts a function as an argument or returns one. Array methods such as `map`, `filter`, and `reduce` are higher-order: you supply the behavior and they supply the traversal. A function can also build another function, as in a factory that returns a tax calculator configured with a rate. A related idea is the identity monad, a simple wrapper that carries a value and lets you apply functions to it while keeping the wrapper intact.

## Composition and pipelines

Composition means feeding the output of one function into the next. A small `compose` helper can combine several functions into a single step, applying them right to left. This lets you describe a data pipeline as a series of clear transformations: filter the records you want, map them to new values, then reduce to a summary. Keeping each step small and pure makes the whole pipeline easy to change.

## Demo: order analyzer

The demo runs an order list through a pipeline of pure functions, with a toggle for adding tax.

```html

<script>
  var orders = [
    { id: 1, total: 120, status: "complete" },
    { id: 2, total: 85, status: "pending" },
    { id: 3, total: 200, status: "complete" },
    { id: 4, total: 45, status: "complete" }
  ];

  function isComplete(order) { return order.status === "complete"; }
  function withRate(rate) {
    return function (order) { return order.total * (1 + rate); };
  }
  function add(a, b) { return a + b; }
  function compose(...fns) {
    return function (value) {
      return fns.reduceRight(function (acc, fn) { return fn(acc); }, value);
    };
  }
  var round2 = function (n) { return Math.round(n * 100) / 100; };

  function analyze(rate, label) {
    var totals = orders.filter(isComplete).map(withRate(rate));
    var sum = totals.reduce(add, 0);
    var largest = totals.reduce(function (best, n) { return n > best ? n : best; }, 0);
    var display = compose(round2)(sum);
    document.getElementById("out").textContent =
      label + "\n" +
      "Completed orders: " + totals.length + "\n" +
      "Totals: " + totals.join(", ") + "\n" +
      "Sum (piped through compose): " + display + "\n" +
      "Largest order: " + round2(largest);
  }

  document.getElementById("plain").addEventListener("click", function () {
    analyze(0, "Plain totals");
  });
  document.getElementById("tax").addEventListener("click", function () {
    analyze(0.08, "Totals with 8% tax");
  });
  analyze(0, "Plain totals");
</script>
```
