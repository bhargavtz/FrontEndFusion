# Fluent API

A fluent API (or fluent interface) is a style of designing objects so that method calls read like a sentence. The trick is simple: each configuration method mutates internal state and returns the same object, usually with `return this`. That lets callers chain steps together instead of writing a long series of separate assignments.

## A chainable article builder

Imagine building an HTML article. Rather than passing a dozen arguments to a constructor, you can create an `Article` object and call `article.title("...").paragraph("...").tag("...")` in sequence. Each method stores a value and hands the object back, so the next method can be called immediately. A final `render()` method returns the assembled string. Because the chain is ordinary JavaScript, you can break it across lines, store intermediate objects, or loop over data to add paragraphs.

## Trade-offs

Fluent code is compact and pleasant when the number of options is large and the operations are related. It does make errors harder to pinpoint — a long chain produces one expression — and returning `this` means the methods are not pure. Keep chains short, give methods descriptive names, and avoid hiding side effects such as network calls inside them.

The demo constructs an article from form fields using a small chainable builder, then shows both the rendered result and the generated markup.

      function esc(s) {
        return String(s).replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;");
      }

      // A tiny fluent interface: every configuration method returns `this`.
      function Article() { this.titleText = ""; this.tagText = ""; this.paragraphs = []; }
      Article.prototype.title = function (t) { this.titleText = t; return this; };
      Article.prototype.tag = function (t) { this.tagText = t; return this; };
      Article.prototype.paragraph = function (p) { this.paragraphs.push(p); return this; };
      Article.prototype.render = function () {
        var parts = ["<article>"];
        parts.push("<h2>" + esc(this.titleText) + "</h2>");
        this.paragraphs.forEach(function (p) { parts.push("<p>" + esc(p) + "</p>"); });
        if (this.tagText) parts.push("<span class='tag'>" + esc(this.tagText) + "</span>");
        parts.push("</article>");
        return parts.join("\n");
      };

      document.getElementById("build").addEventListener("click", function () {
        var lines = document.getElementById("body").value.split("\n").filter(function (s) { return s.trim(); });

        var article = new Article()
          .title(document.getElementById("title").value)
          .tag(document.getElementById("tag").value);
        lines.forEach(function (text) { article.paragraph(text); });

        var markup = article.render();
        document.getElementById("preview").innerHTML = markup;
        document.getElementById("out").textContent = markup;
      });
    </script>
