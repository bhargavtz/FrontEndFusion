# Modularization Techniques

As a script grows, keeping everything in one global scope becomes unmanageable. Modularization breaks code into units with clear inputs and outputs, each hiding its internals. Over time JavaScript has developed several ways to do this, from hand-built patterns to standardized syntax.

## ES modules and the IIFE pattern

ES modules are the standard today. A file becomes a module when it is loaded with `type="module"`. It has its own scope, and it can `export` values and `import` them elsewhere. Named exports expose several members, while a default export provides one primary value. Modules are static, which lets bundlers analyse and optimise them.

Before modules existed, the immediately invoked function expression, or IIFE, provided privacy. You wrap code in a function that runs at once; variables inside stay private, and you return only the public API. This is the basis of the revealing module pattern and still appears in older code and in script tags that must run without a build step.

## AMD and CommonJS

AMD, used by loaders such as RequireJS, defines modules with a `define` call that lists dependencies and receives them as arguments. It loads modules asynchronously, which suited early browsers. CommonJS is the module system built into Node.js: `require` pulls in a module and `module.exports` publishes values. It is synchronous and remains common on the server and in tooling configuration.

The demo builds two tiny modules at runtime using the IIFE and CommonJS ideas, then calls their methods so you can see how hidden state is exposed through a small public surface.

      var out = document.getElementById("out");
      var Counter = (function () {
        var count = 0;
        function inc() { return ++count; }
        function value() { return count; }
        return { increment: inc, current: value };
      })();

      function defineCommonJS(factory) {
        var module = { exports: {} };
        factory(module, module.exports);
        return module.exports;
      }
      var math = defineCommonJS(function (module, exports) {
        var pi = 3.14159;
        exports.circleArea = function (r) { return pi * r * r; };
        exports.double = function (n) { return n * 2; };
      });

      document.getElementById("iife").addEventListener("click", function () {
        out.textContent = "IIFE revealing module\nincrement() -> " + Counter.increment() +

          "\nDirect access to private 'count': " + (typeof window.count);
      });

        out.textContent = "CommonJS-style module\ncircleArea(2) -> " + math.circleArea(2).toFixed(4) +
          "\ndouble(7)     -> " + math.double(7) +
          "\nPrivate 'pi' visible outside: " + (typeof window.pi);
      });
      document.getElementById("both").addEventListener("click", function () {
        var n = Counter.increment();
        out.textContent = "Composing modules\ncounter value      -> " + n +
          "\ndoubled by math    -> " + math.double(n) +
          "\nES modules use import / export instead of these wrappers.";
      });
      out.textContent = "Click a button to exercise a module pattern.";
    </script>
