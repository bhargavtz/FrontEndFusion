# Loops

Loops let a block of code run many times without repeating it in the source. Choosing the right loop makes the intent clear and avoids common mistakes with indexes and object keys.

## Counted loops: for and while

A `for` loop packs three parts into one line: an initializer, a condition checked before each pass, and an update step. It is ideal when you know how many times to iterate, such as walking positions from zero to a length. A `while` loop checks its condition each round and is better when the number of passes depends on a changing situation. A related `do...while` form checks the condition after running the body, guaranteeing at least one pass.

## Iterating collections with for...of and for...in

`for...of` loops over the values of an iterable such as an array or string, so you rarely need to touch an index. `for...in` walks the enumerable keys of an object, including inherited ones, which is why it is best avoided for arrays unless you filter with `hasOwnProperty`. When you need both position and value, `forEach` or the `entries` method of an array can supply them.

## break, continue, and labels

`break` exits the nearest loop immediately, while `continue` skips the rest of the current pass and moves on. Labels are names placed before a loop, allowing `break outer` to leave a specific enclosing loop rather than just the innermost one. Used carefully, these statements simplify early exits from searches and nested iterations.

## Demo: times table

The demo uses nested `for` loops to build a multiplication triangle, then a `for...of` loop for a sum and a `while` loop with `break`.

<script>
  function build() {
    var n = Number(document.getElementById("size").value);
    var lines = [];
    for (var row = 1; row <= n; row++) {
      var cells = [];
      for (var col = 1; col <= row; col++) {
        cells.push(String(row * col).padStart(3, " "));
      }
      lines.push(cells.join(" "));
    }
    var values = [1, 2, 3, 4, 5];
    var sum = 0;
    for (var value of values) { sum += value; }

    var count = 0;
    while (true) {
      count++;
      if (count >= 3) { break; }
    }

    var skipped = [];
    for (var k = 1; k <= n; k++) {
      if (k === 2) { continue; }
      skipped.push(k);
    }

    document.getElementById("out").textContent =
      lines.join("\n") + "\n\n" +
      "for...of sum of 1..5: " + sum + "\n" +
      "while stopped at: " + count + "\n" +
      "rows after continue: " + skipped.join(", ");
  }

  document.getElementById("build").addEventListener("click", build);
  build();
</script>
