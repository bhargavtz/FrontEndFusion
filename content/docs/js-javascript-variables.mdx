# JavaScript Variables

A variable is a named place to keep a value so you can use it again. Almost every line of useful JavaScript reads a variable, changes one, or combines several. Getting comfortable with declarations early makes everything else easier.

## Declaring and naming variables

You create a variable with `var`, `let`, or `const`. Modern code prefers `let` for values that will change and `const` for values that will not. A declaration can stop at the name, giving the variable the special value `undefined`, or it can include an equals sign to assign an initial value right away.

Names are case-sensitive and may contain letters, digits, underscores, and dollar signs, but cannot start with a digit. Choose names that describe the data, such as `userName` or `totalPrice`, because you will read them far more often than you write them.

## Using and updating values

Once declared, a variable is used simply by writing its name. Assigning a new value replaces the old one. With `let` this is allowed; with `const` it raises an error, which is exactly why `const` is a good default. Variables respect scope: a name declared inside a function is not visible outside it.

```js
let score = 0;
score = score + 10;
const player = "Ada";
```

## Arrays and objects

When values belong together, containers beat a long list of separate names. An array is an ordered list accessed by numeric index starting at zero. An object stores named properties, read with dot notation or with brackets when the key is dynamic. Both can be nested inside each other to model real data.

```js
const colors = ["violet", "teal", "amber"];
const user = { name: "Ada", age: 27 };
colors[0];      // "violet"
user.name;      // "Ada"
```
