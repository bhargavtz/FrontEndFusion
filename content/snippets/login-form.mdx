## Notes

- Email and password fields use visible labels and inline validation.
- The password field has a show/hide toggle with an accessible name.
- Social login buttons are keyboard reachable and include brand icons.
- No data leaves the browser — submit is handled client-side only.

## Usage

```tsx

export function Page() {
  return <LoginForm />;
```
